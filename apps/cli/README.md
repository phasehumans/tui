<h4 align="center">a ui library for terminal agents</h4>

@trydecember/tui is a terminal UI library for AI agents built with React and Ink. Add customizable components directly into your codebase so you own the code.

[tui.trydecember.com](https://tui.trydecember.com)

- **Own your code:** Adds components directly to your project so you can edit and customize everything.
- **Built for AI agents:** Designed for streaming text, thinking blocks, tool calls, and code diffs.
- **Built-in themes:** Comes with 7 color themes out of the box, or easily customize your own.
- **Auto-installs dependencies:** Automatically detects and installs any needed packages for you.

### Get Started

1. Initialize in your React + Ink repository:

```bash
npx @trydecember/tui init
```

2. Add components to your project:

```bash
npx @trydecember/tui add streaming-text
```
